# Concept notes

Use this area for short, linked notes that answer one conceptual question. Each note should state
prerequisites, a mental model, a small experiment, and a connection to an exercise. Prefer primary
sources and a short reading path over resource dumps.

Use [the resource guide](resources/README.md) for datasets, models, papers, engineering
documentation, and news. Use [the platform storyline](platform-storyline.md) to understand how
individual notes connect to the support-ticket system.
