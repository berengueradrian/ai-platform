# Exercise 01 — Dense retrieval baseline

Given a corpus of internal Markdown, HTML, and PDF-derived text, build the smallest
dense retrieval system that returns top-k passages for natural-language questions.

Define chunking, embedding, similarity, metadata, and a query protocol. Create a small
relevance set before tuning. Report Recall@k and representative misses. Your design must
state what dense retrieval is expected not to handle well.
